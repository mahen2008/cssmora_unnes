PANDUAN GANTI FOTO
Semua foto di folder ini hanyalah gambar contoh. Ganti dengan fotomu memakai NAMA FILE YANG SAMA (timpa file lama),
maka website otomatis memakai foto barumu tanpa perlu mengedit HTML.

logo.png           logo organisasi (kotak, PNG transparan, 256x256)
hero.jpg           latar beranda (landscape, 1600x900)
tentang.jpg        foto bagian Tentang (4:3, 1200x900)
galeri/g1-g9.jpg   foto galeri (4:3, 1200x900)
prestasi/p1-p6.jpg foto prestasi (16:10, 1200x750)
karya/k1-k6.jpg    foto karya awardee (16:10, 1200x750)

Saran: format JPG, ukuran file di bawah 300 KB (kecilkan lewat squoosh.app / tinypng.com).
Foto dengan rasio berbeda tetap aman karena otomatis dipotong rapi (object-fit: cover).

anggota/           foto anggota divisi (persegi 1:1, 400x400). Nama file: <id-divisi>-<nomor>.jpg
                   id: bph, keilmuan, keagamaan, pengabdian, minatbakat, media, jejaring
Nama, jabatan, program kerja, dan jumlah anggota diedit di index.html pada bagian window.DIVISI.
